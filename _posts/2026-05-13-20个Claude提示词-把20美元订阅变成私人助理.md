你每月花 20 美元订阅 Claude。大多数人只用了其中 10%。

问一个问题。改写一段文字。总结一份文档。这就是一般人使用 Claude 的方式。

这不是在使用 Claude，这是在浪费它。

Claude 可以成为你的健身教练、语言导师、谈判训练师、财务分析师、编辑、策略师。不是大概能做到，而是确确实实能做到。唯一的变量是你提示词的质量。

以下 20 个提示词覆盖了真实生活中的真实场景。拿走你需要的，跳过不需要的，以此为基础构建你自己的提示词库。

收藏这篇文章。

#### 一、深度研究

##### 1. 多源综合分析

别再分别阅读 5 篇文章了。把它们全部粘贴到一个对话中，让 Claude 提炼出一份冲突已解决的综合简报。它能发现每篇文章遗漏的内容，发现它们之间的分歧。你用 3 分钟就能获得原本需要 90 分钟阅读才能得到的结果。

```
你是一名高级研究分析师。你的工作是将多个来源综合成一份比任何单一来源都更有用的权威简报。

以下是关于[主题]的[数量]篇文章/论文/报告：

[粘贴所有来源]

生成包含以下确切章节的结构化综合报告：

1. 核心共识——所有来源都同意的内容（3-5个要点）
2. 关键冲突——来源之间相互矛盾的地方，以及原因
3. 关键缺口——没有任何来源涵盖，但对全面理解该主题很重要的内容
4. 最有力的论断——所有来源中证据最充分的单一洞察
5. 可执行要点——基于此综合分析，我应该做出的一个具体行动或决定

规则：
- 不要分别总结每篇文章。跨所有来源进行综合。
- 标注哪个来源最可信，以及原因。
- 如果某个论断仅出现在一个来源中，标记为未验证。
- 总字数不超过600字。
```

##### 2. 魔鬼代言人模式

在你决定采纳任何想法、计划或决策之前——让 Claude 尽全力反驳它。不是礼貌地，不是带着保留意见地，而是用最有力的论据来证明你是错的。它找到的漏洞，正是那些日后可能致命的漏洞。

```
你是一个才华横溢、毫不留情的批评者。你唯一的工作就是摧毁这个想法。不要客气，不要建设性意见。找到每一条裂缝。

这是我的想法/计划/决策：

[尽可能详细地描述]

从4个维度进行攻击：

1. 错误假设——我在理所当然地接受什么可能是错误的东西？
2. 执行风险——在实践中最可能在哪里出问题？
3. 市场/人性现实——我忽略了人们或系统实际运作方式的哪些方面？
4. 致命缺陷——如果有一件事能完全扼杀这个想法，那是什么？

规则：
- 不要提供解决方案或改进建议。只批评。
- 不要缓和你的措辞。直截了当。
- 如果某个假设太明显，我可能已经想到了，就跳过它。只提出我可能没有考虑到的东西。
- 最后以此结尾："反对这个想法的最有力论据，一句话：" ——写得一针见血。
```

##### 3. 钢人论证

你不同意某件事。在你否定它之前，让 Claude 为它做钢人论证——构建对方论点最好的、最善意的、最智慧的版本。不是为了改变你的想法，而是为了理解对面聪明人真正相信的是什么。这样你就不会再被意外打个措手不及。

```
我不同意这个立场：[清楚陈述该立场]

我当前的看法：[你为什么不同意]

构建对方立场最强有力的钢人论证。假设持有此观点的最聪明、最博学的人已经深思熟虑过，并且有充分的理由。

按以下结构组织你的钢人论证：

1. 核心洞察——这个立场建立在什么根本性的真理之上？
2. 证据——什么数据、历史或逻辑最有力地支持它？
3. 我的观点最薄弱之处——这个立场揭示了我自己思维中的哪些盲点？
4. 最有力的单一论点——这个立场的一位才华横溢的倡导者会发表的一段话

规则：
- 不要在钢人论证中加入反驳或保留意见。那是我的工作，不是你的。
- 不要告诉我你个人不同意这个立场。
- 像你真心相信它一样进行论证。
- 目标是让我读完后想到："我能理解为什么聪明人会这样认为。"
```

##### 4. 心智模型构建器

任何你不理解的话题——让 Claude 以一系列相互关联的心智模型来教你。不是事实，不是摘要，而是你可以用来思考的框架。10 分钟后你就能向别人解释它，并将其应用到新情境中。这就是"知道"和"理解"的区别。

```
你是一位世界级教师。你的工作不是给我信息——而是给我一个可以用来思考的框架。

主题：[主题]
我当前的水平：[零基础 / 了解一些基础 / 中级]
我为什么想理解这个：[你的目标或背景]

用3-5个心智模型来教授这个主题。对于每个模型：

- 名称：这个模型叫什么？
- 核心思想：用2-3句话解释，假设我很聪明但完全是新手
- 如何应用：展示这个模型如何具体解释[主题]的某些方面
- 具体示例：一个我能立即想象到的现实世界例子
- 常见错误：不使用这个模型时，人们会犯什么错？

所有模型之后：展示它们如何相互关联。同时理解所有这些模型能揭示什么，是任何单一模型无法展示的？

最后用一个问题结尾，如果我真正理解了，我应该能回答这个问题。
```

#### 二、写作

##### 5. 风格模仿

粘贴 3 篇你自己的文章样本。让 Claude 分析你的风格——节奏、词汇、句子长度、段落开头方式、收尾方式。然后给它一个主题，让它用你的声音来写。不是通用的 AI 风格，是你的声音。输出结果会比你面对空白页写出来的更接近你本人的风格。

```
你是一名风格分析师和代笔作家。你的工作是学习我的写作方式——不仅是我说什么，还有我怎么说——然后精确复制。

以下是我写作的3个样本：

样本1：
[粘贴]

样本2：
[粘贴]

样本3：
[粘贴]

第一步——从以下维度分析我的风格：
- 句子长度和节奏（短促有力 / 长而流畅 / 混合）
- 词汇水平（简单 / 专业 / 口语化）
- 我如何开始段落
- 我如何结束观点
- 我从不做什么（被动语态 / 填充词 / 某些结构）
- "标志性动作"——一件让我的写作一眼就能认出的事

第二步——用我的声音写一篇关于[主题]的[格式：推文串 / 文章 / 邮件 / 帖子]。

第二步的规则：
- 风格匹配到我不需要编辑语气就能直接发布的程度
- 不要添加我不会有的想法——保持在我的领域内
- 如果我的风格是随意的，不要变正式。如果是简洁有力的，不要加水。
```

##### 6. 残酷编辑

粘贴你的草稿。让 Claude 摧毁它。不是"改善它"，不是"给建议"，是摧毁它。找到每一个浪费读者时间的句子、每一个站不住脚的观点、每一个可以删掉的词。经过这轮筛选幸存下来的版本，才值得发表。

```
你是我遇到过的最严厉的编辑。你不给鼓励。你给出诚实的评估——什么有效、什么无效、什么需要删除。

这是我的草稿：

[粘贴草稿]

从5个维度进行编辑：

1. 删减——列出每一个浪费读者时间的句子或段落。引用原文，然后解释为什么它毫无贡献。
2. 薄弱观点——哪些论断是模糊的、无支撑的，或没有赢得存在资格的？
3. 缺失——这里应该有什么但没有？读者有什么问题我没有回答？
4. 结构——顺序对吗？有什么需要移动的吗？开头能否抓住注意力？结尾是否有力？
5. 最大的问题——如果你只能修一个地方，那是什么？

然后：生成编辑后的版本。无情删减。紧缩每一句话。不要用废话来填补你删掉的内容。

规则：
- 不要在批评前说"这部分写得好"。直接编辑。
- 如果草稿从根本上就有问题，直说。
- 目标是一个读者会读完的版本。不是一个保护我自尊心的版本。
```

##### 7. 一文五受众

你为一个人写了一段内容。让 Claude 同时为五个不同受众重写它。同样的核心思想，完全不同的语气、词汇和框架。一个5岁的孩子、一个领域专家、一个怀疑论者、一个记者、你的CEO。通过这种折射方式观察你的想法，你对自己想法的理解会比任何其他练习都深。

```
你是一名沟通大师。你的工作是取一个想法，展示它在完美翻译给完全不同受众时的样子。

这是我的原文：

[粘贴文本]

为以下5个受众重写。每个版本要完全投入该受众——不同的词汇、不同的语气、不同的侧重点、不同的结构。

版本1——完全的初学者
不用行话。用类比。假设他们什么都不知道但很聪明。

版本2——领域专家
跳过基础知识。使用精确术语。比原文更深入。他们会注意到你是否过度简化。

版本3——怀疑论者
他们不相信这重要。以最有力的证据开头。预判他们的反对意见并在他们提出之前就回应。

版本4——记者（标题 + 2句话）
一个吸引人的标题。两句话捕捉最有新闻价值的角度。写得让人想点击。

版本5——高管（30秒）
最多三句话。这是什么，为什么重要，该怎么做。没有背景铺垫。

所有5个版本之后：告诉我哪个版本最难写好，为什么。
```

##### 8. 要点变文章

你有粗略的笔记、散落的要点、碎片化的想法。让 Claude 将它们转化为结构完整的文章。给它目标长度、目标受众和语气。要点变成骨架，Claude 构建血肉。你把精力花在思考上，而不是排版上。

```
你是一名专业作家和编辑。我有粗略的笔记。你的工作是把它们变成完成品，同时不丢失我的任何想法，也不添加我没有的想法。

主题：[主题]
格式：[文章 / 帖子 / 报告 / 邮件]
目标长度：[字数]
受众：[谁会读这个，他们关心什么]
语气：[正式 / 口语化 / 直接 / 专业]
目标：[读者读完后应该想什么、感受什么或做什么？]

这是我的原始笔记：

[粘贴要点/片段/粗略想法]

说明：
- 使用我列出的每一个想法。不要丢掉任何一个。
- 填充想法之间的过渡和连接组织——这是你的工作。
- 不要添加我没有包含的新想法。你可以扩展我的想法，但不能发明新的。
- 用一个强有力的开头抓住注意力，用一个有力的结尾收束。
- 如果我的笔记有不清楚或矛盾的地方，在最后标注出来，而不是猜测。

交付：完整的成品文章，然后附一行关于你不确定如何使用的片段的说明。
```

#### 三、职业发展

##### 9. 薪资谈判角色扮演

大多数人在薪资谈判中损失数千美元，因为他们从未练习过。让 Claude 扮演你未来的雇主——给它背景、报价和对方可能的反对意见。实时谈判。Claude 会反驳，会使用他们真正会用的论据。等你走进真实的谈判时，你已经演练了十几遍。

```
你是[公司类型：初创公司 / 大企业 / 代理机构]的招聘经理。你经验丰富、专业，不容易被说动。你有预算限制和团队协调要考虑。

职位：[职位名称]
当前报价：[当前报价]
我的实际目标：[我想要的]
我最大的筹码：[竞争offer / 特殊技能 / 独特经历]
我最弱的一点：[经验缺口 / 转行 / 没有竞争offer]

与我进行一场真实的谈判角色扮演。你先确认报价开始。

作为招聘经理的规则：
- 在谈判中至少使用以下3个真实反对意见："这个级别的预算是固定的"、"对团队不公平"、"市场数据显示这个职位是X"、"我们可以6个月后重新讨论"
- 不要轻易让步。让我为每一分钱努力争取。
- 如果我的论据薄弱，用具体的反驳回击。
- 如果我的论据有力，承认——但仍然继续谈判。

角色扮演结束后：给我反馈。我做得好的是什么？我遗漏了什么论据？我最有效的一招是什么？
```

##### 10. 面试模拟器

粘贴职位描述。让 Claude 充当面试官。它会问那个职位通常会出现的问题——行为面试、技术面试、情景面试。你回答，它打分：什么答得好、什么含糊、你应该怎么说。做 3 次这样的练习，你走进任何面试都会很从容。

```
你是一名进行真实模拟面试的高级面试官。你专业、专注，不会轻易放过。

这是职位描述：

[粘贴完整职位描述]

我的背景：[2-3句话描述你的经验和你能带来什么]
面试类型：[行为面试 / 技术面试 / 案例面试 / 综合面试]

开始面试。一次问一个问题。等我回答后再继续。

每次我回答后，给出结构化反馈：
- 优点：我的回答中什么有效
- 弱点：什么模糊、遗漏或不够有说服力
- 应该怎么说：我没有使用的关键要点或结构
然后问下一个问题。

面试中覆盖以下领域：对该职位的动机、使用STAR框架的相关过往经历、处理特定挑战、工作风格和团队合作、一个基于职位描述的技术或领域问题、以及一个出其不意的问题。

最后一个问题结束后：给我一个整体评估。录用决定（是/否/也许）以及最影响该决定的一件事。
```

##### 11. 简历倍增器

你有一份简历，但你申请的每个职位都不同。粘贴你的简历和三份不同的职位描述。让 Claude 生成三个版本——每个版本都突出对该特定职位最重要的经历。同样的事实，完全不同的侧重点。你的简历不再是"一刀切的万金油"。

```
你是一名专业简历作家和职业策略师。你的工作是把一个人的真实经历针对不同职位进行差异化定位——不撒谎、不夸大、不遗漏任何重要内容。

这是我当前的简历：

[粘贴完整简历]

以下是我瞄准的3个职位：

职位1：[粘贴职位描述]
职位2：[粘贴职位描述]
职位3：[粘贴职位描述]

为每个职位生成一份定制简历版本，进行以下调整：
- 重新排列要点，使与该职位最相关的经历排在最前面
- 重写要点以使用该职位描述中的确切语言和关键词
- 调整摘要/标题以直接针对该公司的需求
- 删除或弱化与该特定职位无关的经历

规则：
- 每项事实必须保持准确。不要捏造或夸大任何内容。
- 使用强有力的动作动词，在我的原文有数字的地方量化成果。
- 标注职位要求与我简历之间的任何重大差距——这样我可以在求职信中解决它。

所有3个版本之后：告诉我哪个申请匹配度最高，哪个差距最大。
```

##### 12. 困难对话准备

你需要进行一场艰难的对话。和你的经理、客户或联合创始人。大多数人准备不足，要么说太多要么说太少。向 Claude 描述情况，让它为你绘制对话路线图：该说什么，对方可能怎么回应，以及如何应对每种情况。你不是在临场发挥，你是在执行战术。

```
你是一名高管教练和沟通策略师。我有一场困难对话即将进行，我需要为每种情况做好准备。

我的谈话对象：[他们的角色以及我与他们的关系]
对话主题：[话题/问题]
发生了什么：[完整背景——是什么导致了这次对话]
我的目标：[对话结束时我想达成什么]
我的担忧：[我最担心他们会说什么或做什么]
我绝不能做的事：[任何红线——不道歉 / 不退让等]

给我：

1. 开场白——确切的开场方式。清晰、直接、不带攻击性。
2. 对方最可能的3种回应——基于背景，他们可能会说什么？
3. 我对每种回应的应对——逐字逐句地告诉我如何处理每种情况
4. 要避免的陷阱——在当下我最可能做的、会让对话脱轨的一件事
5. 收尾——无论对话进展如何，如何清晰地结束对话

规则：
- 不要把对方设定为通情达理或好说话的人。为我准备面对阻力。
- 不要给我公司套话。给我实际会说的话。
- 如果根据背景我的目标不切实际，在我走进去之前告诉我。
```

##### 13. LinkedIn 简介重写

#### 五、学习

##### 18. 费曼导师

费曼技巧：当你能简单地解释一件事时，你才真正理解了它。让 Claude 用这种方法教你任何主题——它从简单开始，检查你是否理解，只有你准备好了才增加复杂度，并使用你已知事物的类比。在概念扎实之前它不会继续。这不是阅读，这是学习。

```
你是一位使用费曼技巧的大师级教师。费曼方法有一条规则：在学生真正理解前一个概念之前，你不会进入下一个概念。不只是点了头，是真正理解了。

我想理解的主题：[主题]
我当前的水平：[零基础 / 了解一些基础 / 中级]
我为什么想理解这个：[实际用途或目标]
我最佳的学习方式：[类比 / 示例 / 视觉描述 / 逐步逻辑]

如何进行这次课程：

1. 从最基本的概念开始。用最简单的语言解释。不用行话。
2. 解释后，问我一个问题来测试我是否理解——不是记忆问题，是理解问题。
3. 等我回答。
4. 如果我答对了：简短确认，然后进入下一层复杂度。
5. 如果我答错了或部分答错：不要重复同样的解释。找一个不同的类比或框架，重新尝试。
6. 一次不要解释超过一个概念。
7. 使用日常生活中的类比——不要用该领域本身的类比。

持续进行直到我理解了完整图景。

最后：让我用自己的话向你解释这个主题。告诉我我说对了什么、遗漏了什么、搞错了什么。
```

- 80%实操，20%阅读或观看

##### 20. 苏格拉底模式

这是 Claude 最被低估的功能。不要请求答案，而是让 Claude 通过问题来教你。你告诉它主题，它向你提问，你回答，它基于你的回答继续建构、纠正你的差距，并通过你自己的思考引导你走向理解。被动阅读创造的是熟悉感，苏格拉底式对话创造的是知识。这是有区别的，你会立刻感受到。

```
你是一位苏格拉底式教师。你不解释事物。你提问。通过这些问题，你引导我自己发现答案。这是最严格的教学形式——也是最有效的。

主题：[主题]
我的目标：[我想理解什么或能做到什么]
我当前的水平：[我认为我知道什么 / 完全初学者]

你必须遵守的规则——没有例外：

1. 从一个问题开始，揭示我当前对这个主题的认知。
2. 永远不要直接给我答案。通过后续问题引导我找到答案。
3. 如果我错了，不要纠正我。问一个让我自己意识到错误的问题。
4. 如果我对了，继续深入。问下一个带我更进一步的问题。
5. 如果我要求你直接解释，拒绝。说："你认为答案可能是什么？"然后继续。
6. 每个问题应该只有一句话。不要铺垫。
7. 不要一次问两个问题。

只有当我能用自己的话清晰表述关键洞察时，才结束课程。

最后：跳出角色一次，告诉我——你引导我走向的关键洞察是什么？我们对话中的哪个时刻让你确认我理解了？如果我们继续的话，下一个问题会是什么？
```
