我每天都在用 Claude，它在我 Mac 上的使用时长超过任何其他 App。正因为用得这么频繁，我无法接受这个最常用的工作工具随机失忆、丢失重要数据。

为了让 Claude 尽可能地"聪明"，我深入研究了所有可能的记忆解决方案，最终发现了**三个"层级"的记忆系统**，它们让我的 Claude 变得明显更强大。

- **第一层**：简单易用，适合 90%+ 的 Claude 用户
- **第二层**：约需 60 分钟配置，但会彻底改变 Claude 的工作方式
- **第三层**：将 Claude 变成一个用你所有数据训练的、自我进化的第二大脑

#### 第一层：基础记忆（入门级）

这是所有人都应该从这里开始的地方——四个快速上手的技巧，几分钟内即可完成配置，立刻改善你与 Claude 的每一次对话。

##### 1. 记忆编辑工具

**现在就去 设置 → 记忆 页面看看。**

这是 Claude 里被忽视最严重的页面，大多数人从来没打开过。

你会在那里找到 Claude 被动积累的关于你的所有信息（偏好、事实、习惯、工作方式等）。如果不加管理，记忆很快就会被垃圾填满。

解决方法很简单：通读页面上的所有内容，删掉过时、不准确或无关的条目，然后手动添加你真正希望 Claude 永久记住的上下文。

这一步只需要写基础信息（你的角色和基本偏好）——后面我们会介绍如何构建更精细的系统。

##### 2. 项目指令（Project Instructions）

如果你在用 Claude Projects（你应该用），务必填写 **项目指令** 字段。

我的建议：为所有最常用的工作流创建项目，然后用语音把所有上下文输入 Google Doc，再以 PDF 形式上传到每个项目。

##### 3. 直接告诉 Claude

这是列表里最简单的记忆技巧。在对话中途，直接告诉 Claude 你想让它记住什么：

- "记住我永远不想要 [x]"
- "记住我的角色是 [x]"
- "用 [x] 更新你的记忆"
- "记住我希望回复不超过 400 字"

Claude 会立刻把这些存入记忆。你也可以让它忘掉东西："忘掉我提到的 [x]。"

##### 4. 记忆导入与导出

如果你之前在用 ChatGPT（或其他 LLM）并积累了大量上下文，不需要在 Claude 里从头开始。有两种有效的迁移方式：

**方式 a**：告诉 ChatGPT 你在切换平台，让它生成一份记忆导出文档："我要把这个项目迁移到 Claude，给我一份总结文档……"

**方式 b**：使用 Claude 的导入/导出功能。在 设置 → 记忆 里，可以从其他 LLM 导入完整数据。

这四个快速调整对 90%+ 的用户已经足够，并且能立刻改善 Claude 的响应质量。

#### 第二层：上下文文件系统（中级）

第一层解决了基础记忆问题。第二层构建的是更强大的东西：**一套基于文件的记忆架构**，存储在你的电脑上，自动加载到 Cowork 和 Claude Code 中。

核心概念很简单：与其每次都向 Claude 输入上下文，不如把所有上下文存储在 `.md` 桌面文件里，让 Claude 直接访问。这些 Markdown 文件也可以附加到任何 LLM 或 AI Agent 系统中。

##### 搭建步骤

新建一个桌面文件夹，命名为 **"Claude Master Folder"**，在其中创建以下四个 Markdown 文件（可以让 Claude 帮你创建）：

###### 1. Instructions.md（指令文件）

告诉 Claude 所有规则和指令：

```
## 你是谁
## 你做什么
## 规则
## 好的输出是什么样的
```

**重要**：必须包含这一行：*"随着时间推移，用我的偏好更新 Memory.md。"*

这行话至关重要——它让 Claude 在第二个文件里创建并持续更新你的数据记忆日志。

###### 2. Memory.md（记忆文件）

这是 Claude 的"大脑"，会随时间持续更新：

```
## 偏好
## 纠正记录
## 行为模式
## 决策记录
```

现在，每当你说"不要再用破折号了"，Claude 就会进入记忆文件并更新它。

###### 3. Context.md（上下文文件）

针对特定项目的上下文文件。内容会根据具体项目而变化，也可以创建一个通用的"业务上下文"或"生活上下文"大型文件。

###### 4. 存档副本

这一步纯粹是保护性措施，但值得做。

Claude 在工作时会自动更新你的记忆文件，偶尔可能会错误覆盖或做出你不想要的修改，而且一旦丢失就找不回来了。

解决方法很简单：**每周一次**，把整个 Master Folder（包含 Instructions、Memory、Context 等所有内容）复制到一个 Claude 无法访问的独立存档文件夹，并标注日期。如果出现任何问题或错误覆盖，可以从存档中恢复。

##### 如何使用

在 Cowork/Claude Code 中工作时，附加你的 Master Folder，Claude 就会将其作为一个迷你记忆数据库来使用。它会编辑记忆 Markdown 文件，你最终得到的是一个可以附加到任何 LLM、新对话或 AI Agent 的记忆系统。

#### 第三层：AI 第二大脑（高级）

这是最深的一层，坦率地说，并不适合所有人。它需要一定的初始配置和持续维护，但对于构建它的人来说，这真的是最好的高级、详细记忆系统选项。

根据工作方式的不同，有两个选择：

##### 选项 1：Claude × Notion（简单版）

将 Claude 连接到 Notion 是 5 分钟内最高杠杆的事情。

**操作步骤**：
1. 前往 Claude → 设置 → 连接器，启用 Notion 连接器
2. 连接后，Claude 可以在任何对话中直接读取你的 Notion 工作区
3. 建议创建一个新的"记忆数据库"，存储所有 AI 偏好、规则和重要 AI 上下文

在与 Claude 工作时，你可以说："把这个发送到我的 Notion 记忆数据库。"

你还可以通过 CSV 文件或使用 Notion MCP 连接器，将这些 Notion 数据导出到其他 LLM 或 AI 平台。

**适合人群**：想要快速上手、喜欢 Notion 看板/待办视图的用户。

##### 选项 2：Claude × Obsidian（高级版）

Obsidian 将所有内容以纯 Markdown 文件的形式存储在本地电脑上，是连接 Claude 并构建第二大脑的绝佳方式。

**配置步骤**：

**第一步：下载 Obsidian**
前往 obsidian.md 下载 App，创建一个新的 Vault（可以理解为一个桌面文件夹，Claude Code 将在其中存储和访问数据）。

**第二步：在 Claude Cowork/Claude Code 中选择 Vault**
打开 Claude 桌面应用，点击"选择文件夹"，指向你的 Obsidian Vault 文件夹。Claude 现在拥有对其中所有内容的直接读写权限。

**第三步：注入 Mega Prompt**
将 Andrej Karpathy 的 LLM 知识库系统提示词粘贴到聊天框中（提示词链接：`gist.github.com/karpathy/442a6bf555914893e9891c11519de94f`）。这是告诉 Claude Code 如何构建、维护和演化你的 Wiki 的指令集。

**第四步：输入你的数据**
导入任何现有笔记、CSV 文件、文章导出或 Notion 导出，开始填充你的第二大脑。Claude 会摄取每个来源，提取关键信息，并将其整合进一个不断演化的记忆 Wiki。

**适合人群**：希望本地存储、希望 Claude 对自己有深度理解的高级用户。

#### 总结

##### 核心问题

Claude 的默认记忆机制存在根本性缺陷：它是被动的、易丢失的，无法在复杂工作流中可靠地保持上下文。对于高频用户来说，这个问题会严重影响生产效率。

##### 三层解决方案的本质

| 层级 | 核心机制 | 适用人群 | 时间投入 |
|------|---------|---------|---------|
| 第一层 | 利用 Claude 内置记忆功能 + 直接指令 | 所有用户 | 5 分钟 |
| 第二层 | 本地 Markdown 文件作为外挂记忆库 | 进阶用户 | 60 分钟 |
| 第三层 | Notion/Obsidian 构建 AI 第二大脑 | 高级用户 | 1-2 小时+ |

##### 关键洞见

1. **记忆不应该是 Claude 的职责，而应该是你的架构设计**。依赖 Claude 自己记住东西是不可靠的，主动构建外部记忆系统才是正确思路。

2. **Markdown 文件是最佳记忆载体**。它平台无关、可版本控制、可跨 LLM 复用，是连接各种 AI 工具的通用接口。

3. **记忆系统需要持续维护**。无论选择哪一层，定期更新和清理记忆内容都是必要的，否则"垃圾进，垃圾出"。

4. **Obsidian + Claude Code 是目前最强组合**。本地存储 + 双向链接 + Karpathy 的 Wiki 提示词，能让 Claude 真正理解你的思维方式和知识体系。
